# 📱 Mobile Finder

A responsive web application to search and explore mobile phone details.  
Live Demo 👉 [Mobile Finder](https://joynul24.github.io/mobile-finder/)

---

## 🚀 Features
- Search mobiles by name and view results instantly
- Display detailed specifications (storage, display size, chipset, memory, sensors, etc.)
- Show additional information like WLAN, Bluetooth, GPS, NFC, Radio, and USB
- Responsive modal design for all devices (mobile, tablet, desktop)
- Clean UI built with Tailwind CSS

---

## 🛠️ Technologies Used
- **HTML5**  
- **CSS3 / Tailwind CSS**  
- **JavaScript (ES6+)**  
- **Fetch API** for data requests  
- **Programming Hero Open API** for mobile data

---

## 📖 How to Use
1. Open the [Mobile Finder Live Site](https://joynul24.github.io/mobile-finder/).  
2. Type a mobile name in the search bar.  
3. Click **Show Details** to view full specifications in a modal.  
4. Close the modal easily with the provided button.
